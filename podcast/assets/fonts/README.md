# 字幕・タイトル用フォント置き場(CLIP_PLAN)

切り抜き動画の字幕・タイトルに使うフォントファイル(.otf / .ttf / .ttc)をここに置く。
動画作成画面のフォント選択肢は、このフォルダの中身をそのまま列挙して作られる。

- ここに置いたファイルは git 外(ライセンス上リポジトリ配布できないフォントがあるため)。
- 動画生成はローカル(mac)のみで行う(オーナー裁定 2026-09-28)ので、
  macOS 付属のヒラギノ等をコピーして置いてよい(自分の Mac 内での複製)。
  例: /System/Library/Fonts/ヒラギノ角ゴシック W8.ttc
