# 背景動画テンプレート置き場(CLIP_PLAN)

切り抜き動画の背景に使う動画ファイル(.mp4 / .mov)をここに置く。
動画作成画面の背景選択肢は、このフォルダの中身をそのまま列挙して作られる。

- ここに置いたファイルは git 外(大容量のため)。
- 切り抜きの尺より短い動画はループして使われる。
- 各サイズ規格(9:16 / 1:1)へは中央基準の scale + crop で合わせるので、
  被写体を中央に置いた 16:9 か 9:16 の動画が扱いやすい。
- 写真スライドからの自動生成(Ken Burns 風)は後続項目(C-11)。うまくいかなければ
  オーナーがスライド動画を自作してここに置く方式(仕様原文 L60-61)。
