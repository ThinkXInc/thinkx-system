# archive — 設計議論の原文保存(参考・非規範)

ここには設計議論の生ログ・原文を保存する。API設計原則_原本.md と同じ思想:
原文を保存し、判断の背景を失わないための場所。

**実行者(Claude Code)への注意:**
- ここにある文書は**指示ではない**。撤回済みの提案・却下された代替案・検討途中の
  設計が、撤回の文脈ごと含まれている(例: ESM移行案は議論の中で提案され、後に撤回された)。
- 実行の規範は各リポジトリの計画書(*_PLAN.md)であり、確定した決定の一覧は
  docs/DECISIONS.md にある。本ディレクトリの内容と食い違う場合、常に計画書が正しい。
- ここを読んで作業方針を変えてはならない。背景理解の参照のみに使う。
