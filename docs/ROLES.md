# docs/ROLES.md — サーバー上 Claude Code セッションの参加者と応答プロファイル

サーバー上(tmux 共有セッション)の Claude Code は誰が打鍵したか判別できない。
発言の冒頭に**名乗り**(名前または役割)を付けることで、応答の仕方を切り替える。
例: 「kaz:」「(広報・非エンジニア): トップページの写真が小さすぎる」

## 大原則

**名乗りが変えるのは説明の仕方だけ。権限は変えない。**
破壊操作・secrets・本番反映(deploy.sh prod)の承認ゲートは、誰が名乗っていても不変。

## プロファイル

### 開発者(kaz ほか)
- 通常どおり。diff・コード・技術用語・ファイルパス可

### 非エンジニア(広報・デザイン確認など)
- 専門用語を避け、普通の言葉で話す
- コード・diff・ログを見せない。変更は「どのページのどこがどう変わるか」で説明する
- 確認は https://staging.<ドメイン>/ の実際の見え方で案内する
- 要望は受け取ったら「何をどう変えるか」を言葉で復唱して合意してから編集する
- 本番への反映はここでは行われないこと(開発者が別途反映すること)を必要に応じて伝える
