哲学とAI─システムに全てが回収される時代にどう豊かに生きるか

  • ビジネス

    市場のルールはもう変わった。思考を切り替えられていますか？

  • 思想

    哲学とAI─プラトンからポパーまで。古代ギリシャ以前から人間は世界に従属的か。

  • プロのAI

    ClaudeCodeは第一線でどう使われているか。プロが教える生産性15倍の世界。

こんな人に

  1. ビジネスのルールがどのように変わるのか知りたい。
  2. 本当の哲学とは何か知りたい。「知的関心の高い人のメンサ」哲学サロンコミュニティ、クリエイタークラスのためのコミュニティに興味がある。
  3. エージェンティックAIでプロが生産性をどのように倍化しているのか知りたい。
MC・SPEAKER

大塚一輝(おおつか・かずき)

「本当の哲学を教える」学術水準の理論哲学で異例の1万フォロワー

連続起業家、独立計算進化学者、現代芸術家

計算理論、代数学、量子物理学、生命科学、哲学、美学、を横断しプラトン以降の哲学的問題を解決し新たな自然科学体系を構成する知識進化に関する学問─第三空間理論─を16歳から構築し続け、フランス Université Grenoble III（現Université Grenoble Alpes パリ圏外でのフランス最上位大学）派遣留学生（2009年)、フランス国営音響音楽研究所IRCAM Forum会員（2009-2010年）として荻生徂徠以降も謎とされる東洋和声合竹の数理構造を研究、合衆国ハワイ州マウイ島で数年に渡り録音収集した生物歌研究による「言語の普遍的数理構造」の研究成果に基づく普遍的言語学習法を小学生から大人まで可能にした『ファーブラー・メソッド』を2027年1月にクロスメディア・ランゲージ社より出版予定。主な論文に「量子論理の非分配性に基づく直交モジュラー束上の計算言語β」。人口の上位２％のIQを持つ人々の国際団体MENSA会員。

大学卒業とともに独立し、現在主流のクロール型ニュースリーダーを自主開発し日本で初めて普及、半年で2万5千ダウンロード、スーツケース一つで世界を放浪、サンフランシスコでハッカーハウス運営、国内初となるAI活用型の投資用不動産分析システムを企画・開発(2025年にM&A)、独自の言語意味解析機械学習アルゴリズムや音声アルゴリズムで複数の特許を保持。

  • 2021年東京大学大学院情報学環客員研究員。
  • 2022年未来工学研究所(米TTCSP科学技術系シンクタンクグローバルインデックス世界3位)客員研究員。
  • 2026年NTTドコモビジネス(株)（旧NTTコミュニケーションズ(株)）AIクラウド事業アドバイザー。
  • 他技術顧問など多数歴任。
