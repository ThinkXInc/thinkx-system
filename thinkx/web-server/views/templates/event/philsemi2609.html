哲学とAI─システムに全てが回収される時代にどう豊かに生きるか

  • ビジネス

    ゲームのルールはもう変わった。思考を切り替えられていますか？

  • 思想

    哲学とはヒューマニティーと別にある。理論哲学で異例の１万フォロワー。機能不全化した民主主義の時代にどう生きるか。

  • プロのAI

    ClaudeCodeは第一線でどう使われているか。プロが教える生産性15倍の世界。

SPEAKER

大塚一輝(おおつか・かずき)

「本当の哲学を教える」学術水準の理論哲学で異例の1万フォロワー

連続起業家、独立計算進化学者、現代芸術家

  • 2021年東京大学大学院情報学環客員研究員。
  • 2022年未来工学研究所(TTCSP科学技術系シンクタンクグローバルインデックス世界3位)客員研究員。
  • 2026年NTTドコモビジネス(株)新規事業アドバイザー。
  • 他多数歴任。

大学卒業時に独立、現在主流のクロール型ニュースリーダーを日本で初めて普及、半年で2万5千ダウンロード、スーツケース一つで世界を放浪、サンフランシスコでハッカーハウス運営、国内初となるAI活用型の投資用不動産分析システムを企画・開発(2025年にM&A)、独自の言語意味解析機械学習アルゴリズムや音声アルゴリズムで複数の特許を保持。

計算理論、代数学、量子物理学、生命科学、哲学、美学、を横断しプラトン以降の哲学的問題を解決し新たな自然科学体系を構成する知識進化に関する学問─第三空間理論─を16歳から構築し続け、パリ外のフランス最上位大学Grenoble Alpes大学に派遣留学生に選出、パリ音響音楽研究所IRCAM Forum会員として荻生徂徠以降も謎とされる東洋和声合竹の数理構造を研究、合衆国ハワイ州マウイ島で数年に渡り録音収集した生物歌研究による「言語の普遍的数理構造」の研究成果に基づく普遍的言語学習法を小学生から大人まで可能にした『ファーブラー・メソッド』を2027年1月にクロスメディア・ランゲージ社より出版予定。
