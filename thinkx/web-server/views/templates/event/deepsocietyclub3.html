  • 2021年東京大学大学院情報学環客員研究員。

大学卒業とともに独立、現在主流のクロール型ニュースリーダーを日本で初めて普及、半年で5万ダウンロード、スーツケース一つで世界を放浪、サンフランシスコでハッカーハウス運営、世界初の本格的な業務用不動産投資分析システムGate.を企画開発(2025年にM&A)、独自の言語意味解析機械学習アルゴリズムや音声アルゴリズムで複数の特許を保持。

計算理論、代数学、量子物理学、生命科学、哲学、美学、を横断する知識進化に関する学問を16歳から構築し続け、EUと世界のErasmus Mundus奨学プログラム正規派遣生に選出されパリ外のフランス最上位大学Grenoble Alpes大学に留学、パリ音響音楽研究所IRCAM Forum会員として荻生徂徠以降も謎とされる東洋和声合竹の数理構造を研究、例年合衆国ハワイ州マウイ島で録音した生物歌研究から導かれた「言語の普遍的数理構造」の研究成果に基づく普遍的言語学習法を小学生から大人まで可能にした『ファーブラー・メソッド』を2027年1月にクロスメディア・ランゲージ社より出版予定。
