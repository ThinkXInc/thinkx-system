# ローカルサーバー起動手順(thinkx web-server)

全ブロック Mac のローカル端末で実行する。

## 起動

```
cd /Users/K00TSUKA/Sources/thinkx-system/thinkx/web-server
./venv/bin/python main.py
```

` * Running on http://127.0.0.1:5000/` が出ればOK。
起動はこのディレクトリから行う(他の場所から main.py を叩くとテンプレートが見つからず 500)。

## 確認

別のターミナルで実行する。

```
cd /Users/K00TSUKA/Sources/thinkx-system/thinkx/web-server
open http://127.0.0.1:5000/
```

ブラウザでサイトのトップが表示されればOK。
個別ページは `http://127.0.0.1:5000/<パス>`(例: `/event/philsemi2609`)。

デバッグモードのため、テンプレート・コードの編集はブラウザのリロードで反映される(再起動不要)。

画像・CSS・JS は本番と staging では nginx が配信していて uwsgi を通らない。
開発サーバーでは main.py を直接起動したときだけ Flask が同じ URL を返す(`local_static_handler`)。
画像が出ないときは、その1枚を直接叩いて確認する。

```
cd /Users/K00TSUKA/Sources/thinkx-system/thinkx/web-server
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:5000/img/event/hero_hall.jpg
```

200 が返ればOK。404 なら views/img/ 下に実ファイルがあるか確認する。

## 停止

起動したターミナルで Ctrl+C。
