# C-0c オーナー確認票

この確認の目的は、画面を改善することではなく、確定した旧ソースを実ブラウザで動かした状態を
再構築前の基準として保存してよいか判断することです。見た目が古い、余白が広い、モバイルで
折返しが不自然という理由だけでは不合格にしません。往時の画面と違う、必要な内容が欠ける、
重なって読めない箇所を基準として残すべきでない場合は不合格です。

## 今確認するもの: `static/` の12枚

### 1. `business_createguide_desktop.png`

- 左側に `CITYWALK Business`、`Home > Create Guide`、4件のコンテンツが上から順に表示される。
- 4件は Giza Pyramid、Mona Lisa、Renaissance、日本語の「構成的な明暗法」。
- タイトル、説明、右上の黒いラベルが読める。
- 右側のマゼンタは異常ではない。変動するGoogle Mapsタイルだけを比較対象外にしたマスク。
- 左側の一覧までマゼンタなら不合格。

### 2. `business_createguide_mobile.png`

- `CITYWALK Business`、パンくず、4件のコンテンツが1列で表示される。
- 4件の順序と文言はdesktopと同じ。
- モバイルでは一覧が地図を覆うため、マゼンタの地図マスクは表示されない。
- 一覧が欠ける、マゼンタで覆われる、横方向に切れて本文を確認できない場合は不合格。

### 3. `business_home_desktop.png`

- 上部に `CITYWALK Business`、右上に組織名・ユーザー名が表示される。
- 薄いグレーの背景上に、機能メニューの白いカードが2段で並ぶ。
- Create Guide、Register New Item、Manage Reservations、Sales Data、User Analysis、Settingsなどの
  カードが欠けず、重ならない。

### 4. `business_home_mobile.png`

- desktopと同じヘッダーとカード群が、狭い幅で縦方向に並ぶ。
- カードが白い領域から消えたり、互いに重なったりしない。
- 画面外へ続くカードは縦スクロール対象なので、1枚内の下端で続いていても異常ではない。

### 5. `business_settings_desktop.png`

- 上部に `CITYWALK Business`、右上に組織名・ユーザー名が表示される。
- 左に3項目の設定ナビゲーション、中央に組織設定フォームが表示される。
- 組織名、組織の種類、ビジネス内容、国などの入力欄が縦に並ぶ。
- ナビゲーションとフォームが重ならず、主要ラベルが読める。

### 6. `business_settings_mobile.png`

- 現在の旧ソースではレスポンシブ対応が不十分で、ヘッダー、左ナビゲーション、フォームが
  狭い幅に押し込まれ、文字が縦方向へ細かく折り返される。
- これは現在の実ブラウザ再現結果であり、スクリーンショット生成失敗ではない。
- この崩れた状態を「旧アプリの基準」として残してよいかをオーナーが判断する。
- 往時のモバイル画面は正常に横配置されていた記憶がある場合、この画像は不合格として指摘する。

### 7. `business_signup_desktop.png`

- 白い背景の中央付近に「はじめましょう」と説明文が表示される。
- 組織名、組織種別、ビジネス内容、国の4入力欄と黒い「次へ」ボタンが縦に並ぶ。
- 初期ページなので地図は表示されない。

### 8. `business_signup_mobile.png`

- desktopと同じ「はじめましょう」と4入力欄が狭い1列で表示される。
- 旧CSSの固定幅により文字の折返しが多いが、入力欄自体は重ならず順番に並ぶ。
- 往時のモバイルSignupがこの折返しではなかった場合は不合格として指摘する。

### 9. `business_top_desktop.png`

- 全面が白い。
- 確定した旧ソースの `business/top` 本文テンプレートが空であるため、この白画面が現在の基準。
- 往時はここに内容があったはずなら、正常とは承認せず「旧資産欠落」として指摘する。

### 10. `business_top_mobile.png`

- desktopと同じく全面が白い。
- 判定基準もdesktopと同じ。

### 11. `index_desktop.png`

- 白いページの左上に小さく `setup complete.` だけが表示される。
- 他のBusiness UIや地図が表示されないことが正常。

### 12. `index_mobile.png`

- desktopと同じく、白いページの左上に `setup complete.` だけが表示される。
- モバイル専用レイアウトはない。

## 今は確認しないもの: `motion/`

- `README.md` は実装者向けの説明であり、オーナーの合否判定対象ではない。
- `alignment.tsv` はプログラム用の対応表であり、読む必要はない。
- オーナーが確認するのは、実収録後に生成される `review_*.mp4` 6本。
- 各動画は左が提供済みground truth、右がローカル再現。地図タイルの絵柄を除き、操作順、速度、
  パネルの開閉、移動軌跡、文言の反映を比較する。
- 現在 `review_*.mp4` は未生成なので、motionの承認はまだ行わない。

## 回答方法

12枚すべて問題なければ「静止画12枚を承認」と回答する。問題があれば、ファイル名と、往時の状態と
異なる箇所を書く。特に `business_settings_mobile`、`business_signup_mobile`、空白の
`business_top_desktop/mobile` は、旧基準として残してよいかを明示する。
