ISO 3166-1国名コード

【2016-04-21更新】

ISO 3166は国名や行政区画・属領を表すコードの国際規格です。国名を表すISO 3166-1、各国の行政区画・属領名を表すISO 3166-2、旧国名を表すISO 3166-3の3つで構成されています。

ISO 3166-1国名コードは、次のとおりに構成されています。日本ではJIS X 0304となっています

  • ISO 3166-1 alpha-2 ― 2文字コード。一般的な利用が推奨されており、最も普及している。
  • ISO 3166-1 alpha-3 ― 3文字コード。コード名から国名を思い浮かべやすい。
  • ISO 3166-1 numeric ― 数字コード。ラテン文字を解さない国での使用に適している。

下の表は、JIS X 0304：2011を基に、 制定後の変更点 を反映したものです。国名コードは、変更される可能性がありますので注意が必要です。

ISO 3166-2行政区画・属領名コードは、ISO 3166-1 alpha-2(2文字の国名コード)と2～3桁の英数字をハイフンで繋げた形式で表記します。後半の英数字部分は、各国の国内標準に準拠していることが多いです。例えば、北海道のコードは「JP-01」で、ハイフンの後の英数字部分は JIS X 0401都道府県コード です。なお、各国の行政区画・属領名コードの一覧は、「ISO 3166-2:JP」(日本)のように、「ISO 3166-2」とISO 3166-1国名コードをコロンで繋げた形式で表記されます。下記表では、「行政区画・属領名コード」の列から、Wikipediaの各国の行政区画コードのページへリンクしてあります。
