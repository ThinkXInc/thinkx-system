# VPC / EC2(terraform)

### 差分チェック(plan・構成図つき。staging の部分は prod にも置換可)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/plan-summary.sh staging
```

### 反映(plan 全差分表示 → yes で apply。staging | prod | eips)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/terraform_apply.sh staging
```

### 破壊(棚卸し全表示 → yes。EIP は台帳が持つので消えない)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/terraform_destroy.sh staging
```

### output を見る(IP など)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/terraform_output.sh staging lb_public_ip
```

### EIP 台帳を見る(どの固定 IP がどの環境・役割のものか)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/terraform_output.sh eips eip_ledger
```

# デプロイ(push 済みの変更をサーバーへ反映)

### prod(この実行が本番反映の承認ゲート。Mac への全履歴 fetch バックアップも自動で走る)
```bash

bash infra/scripts/deploy.sh prod thinkx
```

### staging(サービスは必要なものだけ列挙)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/deploy.sh staging thinkx kazukiotsukacom transformism nginx-web-root loadbalancer
```

# 検証

### 経路疎通チェック(Mac→LB→web→Flask をホップごとに緑/赤で確認)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/check_request_path.sh $(bash infra/scripts/terraform_output.sh prod lb_public_ip) supercom-web1 supercom-lb1
```

### 受け入れ試験(3サイト全ゴールデンルートを LB へ照合)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/acceptance-sweep.sh $(bash infra/scripts/terraform_output.sh prod lb_public_ip)
```

### 証明書の自動更新を検証(dry-run・約1〜2分)
```bash
cd ~/Sources/thinkx-system
bash infra/scripts/check_cert_renewal.sh supercom-lb1
```

# ブラウザ確認

### DNS 切替前にブラウザで本番を見る(vhost 方式のため IP 直打ちは不可・確認後は削除)
```bash
printf '52.197.179.70 thinkxinc.com transformism.art kazukiotsuka.com\n' | sudo tee -a /etc/hosts
```
```bash
sudo sed -i.bak '/^52.197.179.70 /d' /etc/hosts
```

### 監視や凍結前確認などブラウザで本番AWSを直接見る(DNS 非依存・basic auth は staging と同じ)
```bash
open https://prod.thinkxinc.com/ https://prod.transformism.art/ https://prod.kazukiotsuka.com/
```
