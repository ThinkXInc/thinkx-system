```

```

## 初回のみ

branch を作って上流を張る
```
cd ~/Sources/thinkx-system
git fetch origin
git branch develop origin/monorepo
git branch production origin/monorepo
git push origin develop production
git branch -u origin/develop develop
git branch -u origin/production production
```

## 同期が止まったとき

deploy_staging / deploy_production は何も消さずに止まる。

| 表示 | 意味 | 対処 |
|---|---|---|
| `WRONG-BRANCH` | サーバーが対応 branch に居ない | 表示された `checkout -B` を実行して再実行 |
| `DIRTY` | 未コミットの変更がある | commit・push して取り込む。不要なら破棄。きれいにして再実行 |
| `NON-FF` | 対象 branch に無いコミットがある | push して取り込み、早送り可能にして再実行 |

## 原則

- 承認 = 確認した ref から release を切る。承認してから後で切らない。
- 全サービスを足並み揃えて出す。選んで出す仕組みは持っていない。
- staging へ出るのは常に origin/develop。手元の作業ツリーや branch からは出さない(D-58)。
- サーバーは reset で無言上書きしない。明示 ref へ ff-only、消せない変更があれば止める。
- 取りうる値が1つしかないものは、引数にも名前にも書かない(deploy_staging は引数なし)。
