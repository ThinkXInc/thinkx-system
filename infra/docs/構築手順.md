# thinkx-system/infra/docs/構築手順.md
#
# EC2 2台(web/lb)をゼロから建てて全サイト配信・受け入れ試験 green まで。
#

## prerequisites

staging
```
cd ~/Sources/thinkx-system
ENVX=staging
WEB=supercom-web1-stg
LB=supercom-lb1-stg
run() { ssh "$1" "ENVX=$ENVX bash -s" < "infra/setup/$2"; }
```

prod
```
cd ~/Sources/thinkx-system
ENVX=prod
WEB=supercom-web1
LB=supercom-lb1
run() { ssh "$1" "ENVX=$ENVX bash -s" < "infra/setup/$2"; }
```

## 1. terraform apply(2〜3分)

```
bash infra/scripts/terraform_apply.sh eips
bash infra/scripts/terraform_apply.sh $ENVX
```

## 2. ssh alias を新 IP に(1分)

```
bash infra/scripts/terraform_output.sh $ENVX
```

```
vim ~/.ssh/config
```

## 3. deploy key(初回のみ)

```
bash infra/deploykeys/gen_deploy_key.sh thinkx-system libcommon simplicity
```

## 4. secrets 配布(1分)

```
COPYFILE_DISABLE=1 tar --no-xattrs -czf /tmp/secrets.tgz -C infra certs deploykeys
scp /tmp/secrets.tgz infra/setup/check_deploykey.py $WEB:/tmp/
scp /tmp/secrets.tgz infra/setup/check_deploykey.py $LB:/tmp/
```

## 5. web: 基盤(15〜30分)

```
run $WEB setup_user.sh
run $WEB setup_webserver.sh
```

## 6. web: 鍵検証 + monorepo(1〜2分)

```
ssh $WEB 'tar xzf /tmp/secrets.tgz -C /tmp; python3 /tmp/check_deploykey.py thinkx-system'
ssh $WEB 'python3 /tmp/check_deploykey.py libcommon'
ssh $WEB 'python3 /tmp/check_deploykey.py simplicity'
run $WEB clone_monorepo.sh
```

## 7. .env / assets 配布(1〜5分)

```
bash infra/etc/push_env.sh $WEB thinkx kazukiotsukacom transformism
bash infra/scripts/push_assets.sh $WEB thinkx
```

## 8. web: サイト + nginx(10〜20分)

```
run $WEB setup_nginx-web-root.sh
run $WEB setup_thinkx.sh
run $WEB setup_kazukiotsukacom.sh
run $WEB setup_transformism.sh
run $WEB setup_claude_connect.sh
```

`setup_claude_connect.sh` は staging のみ(Claude 接続ページ `/connect/`。prod では流さない)。

## 9. lb(15〜30分)

```
run $LB setup_user.sh
ssh $LB 'tar xzf /tmp/secrets.tgz -C /tmp; python3 /tmp/check_deploykey.py thinkx-system'
run $LB clone_monorepo.sh
bash infra/etc/push_env.sh $LB loadbalancer
run $LB setup_loadbalancer.sh
```

## 10. 経路疎通(1分)

```
LB_IP=$(bash infra/scripts/terraform_output.sh $ENVX lb_public_ip)
bash infra/scripts/check_request_path.sh $LB_IP $WEB $LB
```

## 11. 受け入れ試験(1〜2分)

```
LB_IP=$(bash infra/scripts/terraform_output.sh $ENVX lb_public_ip)
bash infra/scripts/acceptance-sweep.sh $LB_IP
```

## 12. staging DNS(staging のみ・5分)

```
bash infra/scripts/terraform_output.sh staging lb_public_ip
```

https://us-east-1.console.aws.amazon.com/route53/v2/hostedzones で
staging.thinkxinc.com / staging.kazukiotsuka.com / staging.transformism.art /
staging.nntmapp.com / staging.truetechjapan.com の A レコードを上記 IP に変更。

```
for d in thinkxinc.com kazukiotsuka.com transformism.art nntmapp.com truetechjapan.com; do dig +short A staging.$d | sed "s/^/staging.$d -> /"; done
```
