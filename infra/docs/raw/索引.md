## 注意点・矛盾

- **CUDA note が自己矛盾**: `cuda12.1` の note 冒頭に「deepspeed は cuda12 非対応なので **cuda11.8 を入れ直せ**、このノートでなく cuda11.8 の note を参照」とある。**cuda11.8 の note は今回未取得**。3a を触るなら要回収。
- **IP の記述ゆれ**: `DB Server (Supercom3c)` に「IP: 192.168.1.9」とあるが、これは 3a の IP。3c の IP と食い違う可能性。**現物で `hostname -I` 確認を推奨**。
- **LB の Routing summary が旧構成**: `Run Supercom3L` の記述は `quantz.sixths.ai → 192.168.1.10:8000` 等で、現行の proxy.conf(192.168.1.8:8005 系)と異なる。**古い情報が残存**している例。
- **`Setup Supercom3c` は 3a の note を親参照**(「まずこの一部を実行 → supercom3: setup & installation」)。共通部分が各 note にコピーされ重複している。

## 構造の発見

`Setup 〜`(一度きりの構築) と `Run 〜`(日常運用) が対になっている。

```
Setup Supercom3a   ←→  Run Main Server 3
Setup Supercom3c   ←→  DB Server (Supercom3c)
Setup Supercom2    ←→  Run Web App Server (thinkx, NNTM) / (Quantz Web)
supercom3L setup   ←→  Run Supercom3L (loadbalancer)
```

この分け方は、移行後の `setup/*.sh`(構築) と `runbooks/*.md`(運用) の構造とそのまま対応する。
