# k00bot2(X 投稿 bot)運用(原本)

構成: xbot-project/(settings.yaml, prompts.yaml, scripts/pipeline/*, run/{daily,monthly}.sh)。
セットアップ:
```
cd k00bot2 && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && chmod +x run/*.sh
```
Monthly(候補生成): sitemap_to_urls -> build_page_urls -> fetch_pages ->
extract_article_candidates -> fetch_x_latest -> merge_candidates
Daily(投稿):
```
python -m scripts.pipeline.post_daily          # 本番
python -m scripts.pipeline.post_daily --dry-run  # テスト
```
crontab:
```
10 6 * * * /src/k00bot2/run/daily.sh   >> /src/k00bot2/data/log_daily.txt 2>&1
20 3 1 * * /src/k00bot2/run/monthly.sh >> /src/k00bot2/data/log_monthly.txt 2>&1
```
注意: candidates.jsonl は merge が毎回作り直すため直接編集しない
(manual_candidates.jsonl に追記 -> merge)。

> 移行後: cron はそのまま web EC2 に移植。bot 自体の実行は Claude 非関与(課金外)。
> 「Claude Code に動作チェックさせる」は対話利用なら $100 枠内。
